# Como instalar este pacote no projeto

1. Extraia o ZIP na pasta principal do projeto React, a mesma que contém `package.json`.
2. O resultado deve ser `CONTEXTO_FORMA.md` na raiz e a pasta `docs/forma/` ao lado de `src/`.
3. Se já existir algum arquivo com o mesmo nome, integre as informações antes de substituir.
4. Abra o projeto no VS Code e use o texto de `PROMPT_INICIAL.txt` em uma nova sessão do Codex.
5. Para continuar em outro PC, mantenha estes arquivos e o código no repositório Git e atualize `ANDAMENTO.md` ao concluir cada etapa.

Este pacote só adiciona documentação e referências. Não contém dependências, código da aplicação ou configuração de hospedagem. Não altera o `README.md`, `AGENTS.md`, `package.json`, `src/` ou `public/` existentes.

O PDF aprovado foi incluído integralmente. As sete telas PNG reproduzem as páginas de mockup desse PDF. As duas fotos originais são referências; a restrição atual permanece: nenhum produto e nenhuma imagem dentro da interface.

Arquivos principais:

- `../../CONTEXTO_FORMA.md`: decisões e limites da entrega atual.
- `GUIA_VISUAL.md`: mapeamento das telas e critérios de fidelidade.
- `REQUISITOS_DO_PDF.txt`: texto extraído das páginas 1–4, sem alterar a especificação.
- `ANDAMENTO.md`: registro editável para continuidade entre sessões.
- `PROMPT_INICIAL.txt`: instrução pronta para iniciar a sessão.
- `referencias/`: PDF, sete telas e duas fotos originais.
- `MANIFESTO_SHA256.txt`: hashes de referência para conferir integridade.
